How it works: keyword (BM25) retrieval over the practice's knowledge base → an LLM (Groq gpt-oss or Gemini Flash-Lite) with strict JSON output (reply, intent, urgency, handoff, staff draft, sources) → guardrails (on-topic only, 500-char limit, session cap). If the AI key is unavailable it falls back to a deterministic rules engine, labelled "offline demo mode". No database, no tracking; the staff inbox lives in your browser.
